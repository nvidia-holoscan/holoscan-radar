Settled SDK and algorithm notes live in the README, so stale open/workaround files are removed.
- **2026-08-31** — **An unconsumed optional output no longer kills the tick.** Nothing exposes an output's wiring to the operator, so it cannot tell "computable" from "wanted", and its emit to an unwired port fails. Wrapping that in `HOLOSCAN_TRY` propagated the failure out of `compute()` and failed the whole activation, so a graph that merely declined an optional output produced nothing and said nothing. First fix, since generalized by the 2026-09-01 entry: discard the result at the five conditional outputs; the failure is confined to that call and siblings still deliver (measured, 32 ticks). The emit helpers gained `[[nodiscard]]`, laundered away from `Output::emit` until now, so a forgotten check is a build error.

## Roadmap (deferred capabilities)

Capabilities deliberately **out of the current scope** — settled as deferred (no
current consumer / larger project), not blocked. Each is enforced today with a
clear error or documented limitation; pick one up when a concrete consumer
needs it.

| Capability | Why deferred | Where tracked |
| --- | --- | --- |
| **Staggered / non-uniform TDM schedules** (varying TX dwell or count) | Needs a per-TX-timing schedule descriptor **and** a generalized `MIMOCoherentCompensationOp` model (the compensation for arbitrary timing is an open design question). Uniform round-robin covers the FMCW workflows; non-uniform is rejected with a clear error today. Settled L12 | [`MIMODeinterleaveOp` README](../../operators/fmcw/mimo_deinterleave_op/README.md) (uniformity pin) |
| **Sum-set ("Harnessing Holes") holey subarray smoothing** | S3 selects a contiguous filled ULA/URA today; a sum-set decomposition (`S_b + S_c`, keeping holes for aperture when the array is sum-set smoothable) would recover more DOF / aperture from holey MIMO co-arrays. Research item; the current gridless estimators consume the contiguous result. Settled L14 (fork 3) | [SubarraySelection README](../../operators/angle_estimation/subarray_selection_op/README.md) |
